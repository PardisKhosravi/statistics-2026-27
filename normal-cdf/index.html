Check against two references

The web table validates the expected values at printed precision; a separate high-precision calculation measures smaller errors.

The NIST EDA normal table prints the area from 0 to |z|. We add or subtract it from 0.5 by symmetry. Its five printed decimals cannot distinguish very small algorithm errors. For example, NIST gives Φ(1)=0.84134, while the independent value begins 0.84134474606854.

The independent values were generated offline with mpmath erfc at 75 decimal digits and stored as 35-digit strings, separate from the JavaScript algorithms. In-browser error arithmetic uses binary64. A displayed zero means agreement at that arithmetic’s resolution, not exact equality in real arithmetic.

Simpson uses N+1 density evaluations away from z=0 and is fourth order on these smooth finite intervals before rounding or truncation dominates. The series uses a recurrence with one update per term, but cancellation grows toward its range limit. Cody evaluates fixed-degree rational polynomials: the center uses no exponentials and the other branches use two for stable scaling. Counts are method-specific, so elapsed time is measured on the same batch instead of equating a density call with a polynomial step.

Median of five batches after warm-up. All three methods use the same eight points within the series range. Rendering and table lookups are excluded; short timings depend on the browser and device.

04

Exact formula, numerical value

An exact expression in a special function does not make that function elementary.

Why there is no elementary antiderivative

For the Gaussian e−x², a consequence of Liouville’s theorem on elementary integration is that an elementary primitive would require a rational function R with R′−2xR=1. A finite pole of R would create a higher-order pole in R′ that −2xR cannot cancel. Thus R would be a polynomial. For any nonzero polynomial R, −2xR has higher degree than R′ and cannot yield the constant 1; R=0 fails as well. Rescaling the variable gives the same obstruction for the standard normal density. This concerns the function of z, not the value of the integral over the entire real line.

Introduce erf and erfc

erf(u) = (2/√π) ∫0u e−t² dt
Φ(z) = ½[1 + erf(z/√2)]
Φ(−|z|) = ½ erfc(|z|/√2)

The change of variable t=x/√2 and symmetry give the first CDF identity; erfc=1−erf gives the second. The Cody implementation calculates the complementary function directly away from the center, so it need not subtract nearly equal quantities to obtain a tiny tail.

Three practical evaluations

  1. Simpson: for |z|<2, integrate the normal density from 0 to |z| and subtract from ½ for the smaller tail. Otherwise integrate directly from |z| to 12 to avoid cancellation. The missing mass beyond 12 is bounded by φ(12)/12, below 2×10−33. Composite weights are 1,4,2,4,…,2,4,1, scaled by the step size divided by 3.
  2. Series: integrate the expansion of e−t² term by term: erf(u)=(2/√π) Σ (−1)ju2j+1 / [j!(2j+1)]. Generate each term from the previous one to avoid explicit factorials. Increasing terms can reduce truncation error but cannot undo floating-point cancellation.
  3. Cody: use published coefficients in three ranges of u=|z|/√2 (up to 0.46875, up to 4, and above 4). The center evaluates a rational approximation to erf; the other ranges evaluate a scaled erfc and multiply by the exponential. This is the calculator’s default method.
