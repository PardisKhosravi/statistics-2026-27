01

Start with the mean

Here SS means the sum of squared deviations from the current mean, not the uncentered sum Σxᵢ².

1 · Definitions and initialization

Mk = (1/k) Σi=1kxᵢ
SSk = Σi=1k(xᵢ − Mk)²

Initialize the computational state k = 0, M = 0, SS = 0. The initial M is a placeholder: an empty sample has no mean. After the first observation, M₁ = x₁ and SS₁ = 0.

2 · Knuth’s recurrence for the mean

Separate the latest value from the previous k−1 observations:

kMk = (k−1)Mk−1 + xk
δk = xk − Mk−1
Mk = Mk−1 + δk/k

The new mean moves by Δ = Mk−Mk−1 = δk/k. Consequently, xk−Mk = (k−1)δk/k.

3 · Account for the shift of the old residuals

For each old value, xᵢ−Mk = (xᵢ−Mk−1)−Δ. Expand the squares, then use Σi=1k−1(xᵢ−Mk−1) = 0. The cross term vanishes:

Σi=1k−1(xᵢ−Mk)² = SSk−1 + (k−1)Δ²

Add the new observation’s residual and substitute Δ = δk/k:

SSk = SSk−1 + (k−1)δk²/k² + (k−1)²δk²/k²
= SSk−1 + (k−1)δk²/k
= SSk−1 + δk(xk−Mk)

Both the old and new means are needed: δ uses the old mean, while the second factor uses the updated mean. In exact arithmetic each increment of SS is nonnegative.

4 · Obtain the variance recurrences

Two definitions answer different questions:

vk = SSk/k   (descriptive variance, k ≥ 1)
sk² = SSk/(k−1)   (unbiased sample variance, k ≥ 2)

Substitute SSk−1 into the SS recurrence:

vk = ((k−1)/k)vk−1 + ((k−1)/k²)δk²,   k ≥ 2
sk² = ((k−2)/(k−1))sk−1² + δk²/k,   k ≥ 3

Base cases: v₁ = 0; s₂² = (x₂−x₁)²/2. The value s₁² is undefined, so it must not be multiplied by zero inside a purported k=2 update. Keeping SS avoids this initialization problem.

02

The three-line core

The same function is used by the trace below and by every hacker in Exercise 2.

const delta = x - state.mean;
state.mean += delta / ++state.n;
state.SS += delta * (x - state.mean);

Start with { n: 0, mean: 0, SS: 0 }. After an update, read state.SS / (state.n - 1) only when state.n > 1. The count increment is included in the second line.

One pass over N values costs O(N) time. The statistical state uses constant memory; storing scores for a teaching table or plot is optional and separate from the algorithm. Welford changes numerical computation, not the definition of the estimates.

04

Why keep corrected SS?

Subtracting two large, almost equal squared sums can lose the small variance through floating-point cancellation.

Optional numerical-stability experiment

Add a constant to the fixed sequence [4, 6, 8, 5]. Translation does not change its exact SS = 8.75. This arithmetic demonstration intentionally uses values outside the penetration-score range.

MethodComputed SSAbsolute error

Naive SS = Σx² − (Σx)²/k. The two-pass method uses Σ(x−mean)². Welford avoids the large squared-sum subtraction and needs no second pass. Floating-point arithmetic is still finite precision; Welford is not guaranteed to be exact for arbitrary inputs. For ordinary scores near 0–10, streaming updates are the main practical advantage.
