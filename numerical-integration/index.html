03

When the distinction matters

Three examples separate a real difference in integrability from numerical complications.

Dirichlet · two dense sets, one null set

On [0,1], set f(x)=1 at rationals and 0 at irrationals. Both sets meet every interval, so every lower Darboux sum is 0 and every upper sum is 1. There is no Riemann integral. The rationals have Lebesgue measure zero, so the Lebesgue integral is 0.

A rational midpoint grid gives 1 at every point, regardless of resolution. The application does not mistake this grid result for a Lebesgue integral or pretend to detect irrationality from a floating-point value.

Thomae · discontinuous on a dense null set

At reduced p/q the value is 1/q; at irrationals it is 0. Only finitely many points have values above any positive threshold. The function is continuous at irrationals and discontinuous at rationals, a null set. It is Riemann integrable, and both integrals are 0. 1/√x · separate the two errors

The function is unbounded near 0, so the proper Riemann integral on [0,1] does not apply. Its improper Riemann and Lebesgue integrals both equal 2. On [ε,1], each method approximates 2(1−√ε). The full error also involves the omitted tail 2√ε. Decreasing ε reduces that tail but makes the truncated problem harder at fixed resolution. The substitution x=u² instead gives the constant integrand 2 on [0,1], after extending its limit to u=0.

04

How the numbers are computed

The two algorithms differ in how they assign weights to function values.

For N equal domain intervals, evaluate f at each midpoint and multiply by (b−a)/N. For K value bands Bⱼ=[yⱼ,yⱼ₊₁) (including the top endpoint in the last band), form Aⱼ={x:f(x)∈Bⱼ}. The range estimate uses the midpoint height cⱼ multiplied by the total length of Aⱼ.

Lower sum = Σ yⱼ·length(Aⱼ)
Range estimate = Σ cⱼ·length(Aⱼ)
Upper sum = Σ yⱼ₊₁·length(Aⱼ)

For these examples the positive-length pieces of Aⱼ come from subtracting the superlevel set at the upper threshold from the set at the lower threshold. For example, {x:sin x ≥ y}=[arcsin y,π−arcsin y] on [0,π]. Endpoint membership is immaterial for length; constant pieces at bin edges are assigned to the correct band. The bracket width is Δy(b−a), so refining the height grid shrinks the gap. Bisection introduces a small additional numerical error for sinc.

For bounded Riemann-integrable functions on a compact interval, the Lebesgue integral exists and agrees with the Riemann integral. The numerical sums approach that common value as the relevant mesh shrinks. The preimage implementation exploits the structure of this collection; it is not an algorithm for measuring arbitrary measurable sets.
