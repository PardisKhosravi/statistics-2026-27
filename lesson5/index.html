The connection

A probability under a continuous density is an integral. The calculation depends on what we know about the function and how much accuracy we need.

Exercise 1 isolates the difference between partitioning inputs and grouping output heights. Exercise 2 uses the smooth normal density to compare integration with special-function approximations.
