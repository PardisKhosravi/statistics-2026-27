01

Define the experiment

Both models run together. Within each model, every attacker is a replicate of the same i.i.d. increment process.

Bernoulli · successful penetrations

Xa,i ∈ {0, 1},   P(Xa,i = 1) = p

Attacker a tries system i once. A success adds 1; a failure adds 0. Sa,n counts successful attacker–system attempts for that attacker. Each attempt has the same fixed probability p.

Rademacher · signed score

Xa,i ∈ {−1, +1},   P(+1) = P(−1) = ½

A positive step represents progress; a negative step represents a setback or defensive response. This is a signed educational score, not a count of compromised systems. Its mean increment is zero and its variance is one.

Preparing the default experiment…

Increasing n is studied at checkpoints 8, 32, 128, 512, 2,048 and 8,192, up to the chosen maximum; the maximum itself is also included. Checkpoints reuse prefixes of the same paths. The model additionally assumes independence across attackers: there is no competition, shared vulnerability, adaptation or changing p.

Two different sample sizes: n is the number of increments in each attacker’s score; m is the number of attacker trajectories used to estimate that score’s distribution. More attackers do not alter the theoretical distribution of one attacker’s score.

04

Convergence in probability

The Law of Large Numbers concerns the average of one long trajectory. The m trajectories estimate its probability of being far from the expected increment.

P(|Sn/n − μ| > ε) → 0

For every fixed ε > 0, Chebyshev’s inequality gives P(|Sn/n − μ| > ε) ≤ min(1, σ²/(nε²)). Its right-hand side tends to zero. Thus Sn/n converges in probability to p in the Bernoulli model and to 0 in the Rademacher model.

Outside the tolerance band

nOutside / mObserved probabilityExact probabilityMonte Carlo SEChebyshev bound

Monte Carlo SE = √(q(1−q)/m), using the exact finite-n tail probability q. This describes uncertainty of the estimated probability, not spread of Sn/n. A finite observed fraction can fluctuate and even exceed a theoretical probability bound; the bound applies to the true probability. A zero observed fraction is not proof that q = 0. Checkpoints share path prefixes, so their estimates are dependent. Comparisons use a 10⁻¹² roundoff tolerance at the ε boundary.

05

A normal limit needs the right scaling

Zn = (Sn − nμ) / √(nσ²)   ⇒   N(0, 1)

For Rademacher increments, Zn = Sn/√n: no extra centering or variance correction is needed. For Bernoulli increments with 0 < p < 1, Zn = (Sn − np)/√(np(1−p)). The uncentered quantity Sn/√n has mean p√n and variance p(1−p); it does not converge to N(0,1).

Distance is supz|F(z)−Φ(z)|, evaluated on both sides of every jump, including ties. These are descriptive distances, not KS-test p-values. The exact distance isolates finite-n approximation error; the empirical distance also includes Monte Carlo error of order 1/√m. A single noisy run need not improve monotonically. Normal CDF values use a numerical approximation accurate to about 10⁻⁷. Bernoulli normal approximation can be poor when np or n(1−p) is small. For p = 0 or 1, Bernoulli is deterministic and standardization is undefined.

Rows use nested prefixes of the simulated attackers (up to 50, 200, 1,000 and all m), not fresh independent experiments. They illustrate changing the ensemble size without changing n. Theoretical aggregate variance is mnσ²; only one aggregate is observed per row, so no empirical variance of aggregates is claimed.

More systems n

For Bernoulli, an attacker expects np successes. Absolute spread grows as √(np(1−p)), while the uncertainty in the success fraction shrinks as √(p(1−p)/n). For symmetric Rademacher, the expected total stays zero but its typical magnitude grows on the √n scale. A negative score describes setbacks, not a negative number of penetrations.

More attackers m

The distribution of an individual Sn stays the same. More attackers stabilize its measured histogram and moments. Under the model, E(A) = mnμ and Var(A) = mnσ². Var(A/m) = nσ²/m, while Var(A/(mn)) = σ²/(mn). Aggregating more attackers increases the spread of the total but reduces the uncertainty of the mean.

Bernoulli A counts successful attempts, so a system may contribute more than once. It is not the number of distinct compromised systems. With independent attackers, that distinct-system count would instead have expected value n[1−(1−p)m]. Real attackers often share weaknesses, learn or compete; those effects violate this simple i.i.d. model and are outside this simulation.

Reproduce and investigate

  1. Run the default settings; compare n = 8 with the largest checkpoint using the same stored paths.
  2. Switch models without regenerating data. Check that Rademacher’s normalized variance stays near 1, while its average-score variance shrinks near 1/n.
  3. For Bernoulli p = 0.3, follow the drifting mean of Sn/√n, then inspect the correctly standardized Z plot. Try p near 0 or 1 to see a slower normal approximation; endpoints are deterministic.
  4. Keep the seed and n fixed and change m. Earlier attackers’ paths are preserved, so the effect of adding trajectories can be inspected. New seeds provide alternative realizations; none guarantees monotone improvement.
  5. Change ε and compare observed LLN tails with exact probabilities and the upper bound. Export measurements and include the seed and settings when reporting results.

Method and sources

All plots and reported observations are calculated in your browser; no precomputed success rates or external runtime services.

Generation uses xoshiro128** with four 32-bit state words. A documented mix32 hash seeds a separate stream for each model and attacker from the displayed seed, model tag and attacker index. This supplies reproducible pseudorandom approximations to independent increments; it does not prove independence and is not a cryptographic random generator. Fixed seed + model + attacker gives the same path prefix across changes in n or m. Exact finite-n laws are Binomial(n,p) for Bernoulli and 2·Binomial(n,½)−n for Rademacher. Probabilities are computed with a normalized recurrence around the binomial mode, avoiding factorial overflow. Double precision can underflow negligible extreme-tail probabilities.
