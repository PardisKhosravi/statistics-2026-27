02

One operation. Two algorithms.

Scalar multiplication means repeated point addition, not multiplying the coordinates by k.

The group law

For P = (x₁, y₁), R = (x₂, y₂), use a modular inverse instead of ordinary division:

λ ≡ (y₂ − y₁)(x₂ − x₁)⁻¹ mod 17

For doubling P = R, replace the slope with:

λ ≡ 3x₁²(2y₁)⁻¹ mod 17
x₃ ≡ λ² − x₁ − x₂
y₃ ≡ λ(x₁ − x₃) − y₁

All results are reduced modulo 17. If R = −P, return O. Also P + O = P. Doubling a point with y = 0 returns O.

Worked example: G + G

For G = (1, 5), 10⁻¹ ≡ 12 because 10 × 12 ≡ 1. Then λ ≡ 3 × 12 ≡ 2, x₃ ≡ 4 − 2 ≡ 2 and y₃ ≡ 2(1 − 2) − 5 ≡ 10. Therefore 2G = (2, 10).

Binary double-and-add

Read k in binary. Start at O; double the accumulator for every bit and add G when that bit is 1. This uses O(log k) group operations rather than O(k).

04

What the measurements mean.

The crucial distinction is between a computation that is difficult to invert and a function whose output is designed to resemble random bits.

A one-way relationship

Computing Q = kG is deterministic and efficient. On an appropriately chosen large curve, recovering k from Q and G is believed difficult: this is the elliptic-curve discrete logarithm problem (ECDLP). Our group is tiny, so exhaustive search trivially recovers k.

Uniform inputs, uniform subgroup points

For a point G of order n, the map from k = 0,…,n−1 to its subgroup is a bijection. Excluding k = 0 gives a bijection onto nonidentity points. Equal sampling of these scalars gives equal point frequencies. Coordinate frequencies and coordinate bits can still be biased.

Correlation is only descriptive

Pearson correlation measures linear association under a numeric encoding. Zero correlation does not imply independence. Here Q is entirely determined by k; the relation (k + 1)G = kG + G always holds.

How a cryptographic hash differs

A hash accepts arbitrary-length byte strings and produces a fixed-length digest. It is designed for preimage, second-preimage and collision resistance, with strong diffusion. Ideal hash avalanche behaviour changes about half the output bits on average after a one-bit input change.

What statistics cannot establish

Flat histograms, balanced bits, high empirical entropy or small correlation do not prove one-wayness. One-wayness is a computational property; even a one-way function can reveal some input bits. Our tests describe this experiment, not the security of real ECC.

For the default G, order(G) = 9. The distinct private scalars 1–8 produce eight finite public points. At 9G = O the sequence resets. Sampling k = 1,…,900 mostly repeats this same tiny cycle.
The connection to Ethereum

Real secp256k1 uses the same equation, y² = x³ + 7, but over p = 2²⁵⁶ − 2³² − 977 and with a specified generator of large prime order n. Its private keys satisfy 1 ≤ k < n. Ethereum externally owned accounts use this key relationship for ECDSA signatures. An address is a separate object: the last 20 bytes of Keccak-256 of the 64-byte x ∥ y public key, excluding the 0x04 prefix. Homework 2 follows that pipeline →

Reproducibility and implementation

The curve arithmetic in toy.js is implemented directly in JavaScript: modular inverses, addition, doubling, infinity handling and both multiplication methods. No cryptographic library is used in this assignment. The statistical census uses k = 1,…,order(G)−1 with equal weight. Empirical Shannon entropy is H = −Σpᵢ log₂pᵢ. Undefined correlations are reported explicitly when a coordinate has zero variance.
